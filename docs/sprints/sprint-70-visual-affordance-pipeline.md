## Mission

Replace the current manual multi-tool visual workflow with a **Prism-owned visual affordance pipeline** while deliberately keeping **image generation manual** (external Copilot/tools).

Prism becomes responsible for visual jobs, deterministic prompts, asset tracking, figure insertion, and finished learner package assembly. External tools own image generation only.
