## 1. What the five cases now say a high-quality Expository Resource needs

Across C01–C05, a high-quality PRISM Expository Resource must do **two** things at once:

1. **Instructional integrity** — Construct the *right* understanding for the commissioned purpose, in a coherent progressive order, with enough explanation and representation — including preservation of the **epistemic form** of that understanding (mechanism, distinction, interpretation, formal relation, etc.).
2. **Editorial authorship** — Create a satisfying reading experience: subject-appropriate entry into that purpose, paced emphasis, controlled recurrence, representations that participate, hierarchy that reveals structure, and a single consolidating close appropriate to the epistemic object.

C01–C03 and C05 show that PRISM can often achieve (1) while still failing (2).  
C04 shows that (1) can fail through **neighbouring-brief drift** even when the delivered chapter is internally coherent.

The provisional “authored coherent intellectual experience” definition remains directionally right but is **insufficient** without explicit purpose/epistemic integrity.

## 5. Missing principles

### 5.1 Preserve epistemic form — **ADD (EQ1)**

**Candidate statement:** A high-quality Expository Resource must preserve not only topical coverage but the **appropriate epistemic form** of the understanding commissioned (e.g. mechanism, causal explanation, conceptual distinction, interpretation, competing weighting, uncertainty, qualification, comparison, formal relation).

| Support | Complication |
| ------- | ------------ |
| **C04 hard negative:** coherent A+B (causes + causal roles) without C (historiographical weighting) | Must not be history-specific |

**Decision:** **Add** as first principle. Purpose-fit and epistemic-form preservation are the same quality demand viewed from commission vs discipline.

## 6. Recurrence / redundancy (P4/P8 revisited)

| Kind | Definition | Treatment |
| ---- | ---------- | --------- |
| 1. Conceptual-anchor recurrence | Return to a central test/formulation that consolidates the concept | **Allowed / often desirable** (C05 validity test) |
| 2. Development / qualification / application | Recurrence adds a new cognitive move | **Preferred** (P4 core) |
| 3. Completed-work repetition | Same explanatory work restated without new move (esp. orientation / Closing / reconsolidating figures) | **Harmful** (all five) |

Accessible prose–figure overlap remains **not** type-3 redundancy when the figure adds perceptibility of structure/sequence/contrast.

## 8. Opening (P1 revisited)

Intellectual need ≠ drama, journalistic hooks, surprise anecdotes, or obligatory rhetorical questions.

**C05:** Precise conceptual problem can itself be the entry.  
**C04:** Strong entry into the wrong problem is still purpose-fit failure.  
**All five:** Administrative prospectus still precedes body entry.

Successor: open into the **commissioned** intellectual need by a **subject-appropriate** device; do not lead with unearned machinery.

## 9. Closure (P11 revisited)

| Term | Meaning |
| ---- | ------- |
| Consolidation | Show what the learner can now do/understand |
| Repetition | Restate completed work (dual page Closing) |
| Resolution | Reach an answer appropriate to the epistemic form |
| False resolution | Collapse legitimate plurality into one neat integrated answer (C04) |

Interpretive consolidation may mean understanding **why disagreement persists**, not integrating one final causal model.

Prefer **one** authoritative consolidating close.

## 10. Instructional vs editorial architecture (refined)

| Layer | Judges |
| ----- | ------ |
| **Instructional architecture** | Whether the resource constructs the **commissioned** understanding, in suitable order, with sufficient explanation and representation — **including epistemic-form preservation / purpose-fit** |
| **Editorial architecture** | Whether the reading experience is authored: entry, pacing, emphasis, transitions, representation participation, controlled recurrence, hierarchy, typography, closure |

**Refined finding:**

- When purpose-fit holds (C01–C03, C05), instructional architecture is typically **stronger** than editorial architecture — explaining mediocrity-despite-correctness.
- Purpose-fit / epistemic-form failure (C04) is an **instructional** failure even if the delivered journey is coherently authored for a neighbouring brief.
- Editorial CONCERN is **systematic**; instructional CONCERN is **not**.
