## Mission

Enable Learning Journeys to own a coherent set of journey-level learning outcomes, allocate outcomes and responsibilities to components via commissioning briefs, and have component Episode Plan consume those outcomes as authoritative — reusing EP → DLA → GAM → LS → DP — while standalone products retain GLC → MK → DLO.

**Design principle:** The Learning Journey owns curriculum coherence; components realise their commissioned contribution.
