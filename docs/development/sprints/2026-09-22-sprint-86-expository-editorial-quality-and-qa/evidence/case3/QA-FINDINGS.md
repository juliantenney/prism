## F. Overall synthesis (frozen §F)

### What is working?

- Mechanism-contrast instructional architecture (D1/D2 **STRONG**).  
- Strong intellectual entry (D9 **STRONG**).  
- Clear policing of individual-change and need/foresight confusions (S5/S6).  
- Warranted causal/comparison figures (D5 **STRONG**) — this is what a visual-important case should look like relative to Case 02.  
- Accessible prose that does not trap essential meaning only in images (D15/D6 stance).

### What most limits this resource from feeling like a high-quality authored chapter?

Still editorial architecture: orientation furniture, dual closure, flat hierarchy, and residual teacherly restatement — not failure of the scientific contrast design.

### What does this visual-important case tell us that low-visual Case 02 could not?

When mechanism topology is the learning target, PRISM can generate **purpose-fit causal/comparison figures** that add perceptibility value beyond prose. Case 02’s problem was partly **over-generation / weak warrant**; Case 03 shows D5 can land **STRONG** on a visual-important brief. Integration remains “adjacent but coherent,” not deep mid-argument choreography.

### Which findings now have cross-case evidence?

See §G.

### Which previous hypotheses have been qualified?

- “Figures usually fail warrant” — **qualified** by Case 03 D5 **STRONG**.  
- “Semantic overlap ⇒ editorial redundancy” — **rejected as automatic rule** (accessibility).  
- “Dramatic hook required” — further weakened (S1 explanatory-gap entry works).

### What requires further evidence?

- Humanities/interpretive case (C04) for false-resolution closure norms.  
- Abstract low-visual case (C05) after C02’s over-generation finding.  
- Whether mid-argument figure handoff can improve without harming accessibility.

### E. New candidate findings

- Visual-important briefs can yield high-warrant causal diagrams.  
- Productive contrast structure (two mechanisms → decisive difference → confusion police → application).  
- Instrument: warrant / value / integration + accessible equivalence.

### F. QA instrument observations (no v0.1 edit)

1. **Accessible semantic equivalence ≠ editorial redundancy.** Prose may carry essential meaning also shown visually; that can be correct a11y practice while the figure still adds perceptibility of structure/sequence/comparison.  
2. The heuristic “would removing the image materially weaken understanding?” can **conflict with accessibility** if interpreted to require essential meaning to live only in the image. Flag for v0.2.  
3. Useful provisional test sequence (not adopted as criterion): **warrant → explanatory value/purpose → prose–representation integration**.  
4. D5 remains usable: Case 02 CONCERN vs Case 03 STRONG shows discriminatory power.
