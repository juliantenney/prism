## 1. Strengths (instructional architecture largely sound)

- Strong overall intellectual journey (S1–S8 as recorded).
- Appropriate movement: intuitive updating → conditional direction → base rates → natural frequencies → formal Bayes → changed-prior comparison → transfer → qualification.
- Postponing the formula until after population reasoning.
- Useful controlled comparison of changed prior (S6).

## 2. Observed editorial weaknesses

| Observation | Export / review evidence |
| ----------- | ------------------------ |
| Excessive learner-facing front matter | Header subtitle + Overview + Learning purpose + Knowledge summary (+ Figure 1) before S1 |
| Repetition among opening/orientation elements | Overview / purpose / knowledge summary restate prior–evidence–posterior and base-rate themes that body later develops |
| Generated / teacherly metacommentary rhythm | Regular “this is… / the important word is… / to understand… we first need…” cadence across sections |
| Claim → explanation → restatement | Frequent pattern of stating a claim, explaining it, then restating in near-synonymous prose |
| Insufficient rhetorical variation | Prose weight often similar across routine and threshold moments |
| Insufficient selective emphasis | High-value sentences (e.g. formula-compression line) exist but are not systematically marked by structure/typography |
| Representations sometimes beside prose | Figures appear after sections; prose does not always visibly “use” the figure mid-argument (integration seam) |
| Weak hierarchy below major section level | **0 × `<h3>`** in export; long continuous section prose |
| Productive recurrence vs redundant repetition under-distinguished | Base-rate / conditional-direction themes recur in orientation, body, and closing with uneven added development |
| Internal instructional artefacts as furniture | Explicit **Overview / Learning purpose / Knowledge summary / Closing** labelled regions |
| Repeated / multiple closure | S8 consolidates + page-level Closing restates carry-away; orientation already summarised |
| Functional rather than publishing-grade typography | System UI font stack; even vertical rhythm; limited hierarchical signalling beyond H2 |

## 3. Developmental-edit transformations (evidence, not rules)

Identified rewrite moves that improved a developmental edit of this case. Recorded as **evidence of editorial interventions that worked for Bayes**, not as a canonical chapter template:

1. Replace administrative opening with subject-appropriate intellectual entry.  
2. Compress straightforward explanation.  
3. Create forward momentum between sections.  
4. Visually expose important conceptual contrasts.  
5. Integrate natural-frequency representation into the explanation.  
6. Use rhetorical emphasis selectively at genuine conceptual moments.  
7. Let equations participate in the explanation.  
8. Use comparison structures where comparison is the explanatory task.  
9. Shorten generic transfer prose.  
10. Consolidate closure.  
11. Use typography to expose intellectual hierarchy.

**Do not** treat this list as required beats for every Expository Resource.
