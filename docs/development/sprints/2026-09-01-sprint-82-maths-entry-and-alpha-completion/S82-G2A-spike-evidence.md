### VK observations (visual inspection)

- Four tabs: `123`, `∞≠∈`, `abc`, `αβγ` — λ on Greek tab; fraction/superscript templates on `123`; `d/∂` on symbols tab.
- Keyboard icon inside field is **discoverable**; VK is large on mobile-width view (~45% viewport) but does not obscure the active field.
- Toggle icon opens/closes VK; hamburger menu exposes Insert/Matrix/Font (not needed for spike).

### Accessibility tree (enhanced mode)

- `math-field` exposed as **generic** with `aria-labelledby` → label id (name: "Lagrangian").
- Inner MathLive textbox also exposed with **math speech** name (e.g. `4 'X' 'Y'`) — **duplicate-control risk** for AT.
- Canonical textarea `aria-hidden` while enhanced (**PASS**).
- Fallback mode: single **textbox** per field with correct accessible name (**PASS**).
