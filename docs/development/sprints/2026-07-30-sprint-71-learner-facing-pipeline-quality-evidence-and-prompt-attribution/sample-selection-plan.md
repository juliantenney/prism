# Sprint 71 — Sample Selection Plan

**Goal:** Ensure the approximately **15–20** reviewed resources are deliberately varied, not accidental duplicates.  
**Status:** Active — slots empty until Phase 0 complete and samples assigned.  
**Related:** [STATUS.md](STATUS.md) · [PLAN.md](PLAN.md) · [review-logging-template.md](review-logging-template.md)

Do **not** count a resource toward the Sprint 71 sample target until it appears here with a Sample/Resource ID and review status other than `candidate`.

---

## Variety axes (check coverage as the table fills)

| Axis | Aim for coverage across the set |
| ---- | ------------------------------- |
| Subject / domain | Multiple disciplines (not only one topic family) |
| Learner level / audience | Mix of levels where practical |
| Archetype | understand · apply · analyse · evaluate (and mixed sessions) |
| Source strategy | Source-led **and** topic-generated |
| Assessment | Some with assessment present; some without |
| Delivery context | e.g. self_directed vs facilitated where available |
| Length / complexity | Short and longer / multi-activity resources |
