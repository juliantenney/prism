## Central question

> How do we embed the validated Sprint 71 principles into Prism so that high-quality instructional design is produced by default, authors are asked only for information the system genuinely needs, and discipline-specific evidence can be supplied and retained where Prism cannot generate it appropriately?

---

## Binding priority order

| Order | Workstream | Rule |
| ----- | ---------- | ---- |
| **1** | Platform / system instructional architecture | If Prism can reliably solve it system-side, do not require authors to restate it every workflow |
| **2** | Workflow elicitation | Where the platform cannot infer safely, ask clear instructional questions — not longer free-text prompts |
| **3** | Author-supplied evidence | Where generation is inappropriate (copyright, org, proprietary, authentic datasets), request / store / associate artefacts |
| **4** | Product / UX | Image consistency & persistence; disciplinary representations; headings; navigation |
| **5** | Raise the ceiling | Investigate why strong ~90–91 resources are not yet ~95–98 (aspirational) |

Preserve the Sprint 71 three-layer model. Do **not** collapse into one generic “prompt improvement” workstream.
